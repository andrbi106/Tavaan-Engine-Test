## استفاده

```php
use Tavaan\Testing\TestCase;
use Tavaan\Testing\TestRunner;
use Tavaan\Testing\Mock\Mock;

class MyTest extends TestCase
{
    public function testAddition(): void
    {
        $this->assertSame(5, 2 + 3);
    }

    public function testArray(): void
    {
        $arr = [1, 2, 3];
        $this->assertCount(3, $arr);
        $this->assertContains(2, $arr);
    }

    public function testException(): void
    {
        $this->expectException(\InvalidArgumentException::class);
        throw new \InvalidArgumentException('test');
    }
}

// اجرا از کد
$runner = new TestRunner([new MyTest()]);
$result = $runner->run();
echo $result->summary();
// PASS: 3/3 (failed: 0)

// اجرا از دایرکتوری
$result = TestRunner::runDirectory('tests');

// Mock
$mock = Mock::of(LoggerInterface::class)
    ->shouldReceive('log')->with('info', 'msg')->andReturn(true)
    ->shouldReceive('error')->andReturn(false)
    ->getMock();
```

## Assertion API

- `assertTrue($cond)`, `assertFalse($cond)`
- `assertSame($expected, $actual)`, `assertNotSame($a, $b)`
- `assertEquals($expected, $actual)`, `assertEqualsWithDelta($expected, $actual, $delta)`
- `assertNull($v)`, `assertNotNull($v)`
- `assertCount($expected, $haystack)`, `assertContains($needle, $haystack)`
- `assertArrayHasKey($key, $arr)`, `assertInstanceOf($class, $obj)`
- `assertStringContainsString($needle, $haystack)`, `assertMatchesRegex($pattern, $subject)`
- `assertGreaterThan($expected, $actual)`, `assertLessThan($expected, $actual)`, `assertGreaterThanOrEqual($expected, $actual)`
- `assertEmpty($v)`, `assertNotEmpty($v)`
- `expectException($class)`, `expectExceptionMessage($msg)`, `expectExceptionCode($code)`
- `fail($msg)`, `markTestIncomplete($msg)`
